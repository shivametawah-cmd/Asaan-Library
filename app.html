Backup your data

Download everything in your library as one Excel file: students (active and inactive), the recycle bin, payments, expenses and approval requests. Save it somewhere safe, for example Google Drive or a pen drive. It contains mobile numbers, so do not share it.

When this is on, the backup downloads by itself the first time you open Asaan after 7 days. It cannot run while the app is closed. Turn it on separately on each phone or computer you use. Your browser may ask permission to download files.

Restore from a backup file

Choose a backup file made by Asaan. Restore adds what is missing: students, then their payments, and expenses. It never changes or deletes anything you already have, so it is safe to run again if it stops halfway. The recycle bin and approval requests are kept in the file for your records but are not restored. Payments are linked back to students using the IDs saved in the file, so use a backup made after this update (older files may link only when student names are unique).
